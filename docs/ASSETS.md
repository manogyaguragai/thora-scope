## Notes

- Use node names (not mesh names) everywhere; see mismatch table.
- Morph target order differs between meshes: always resolve by name via `morphTargetDictionary`, never by index.
- Bounding boxes/centroids are the unmorphed base pose (right lobes inflated, every manifest morph = 0).
- The v7 hilum + right lobes (`assets_src/RML_v7.glb`) are scene roots in world space (not under `thorax_root`), see docs/MODEL_INTEGRATION.md.
- Geometry dominates file size: textures are only 0.69 MiB of 8.68 MiB; morph targets multiply vertex data.
- Cameras and ports are scene roots, not children of `thorax_root` (see Nodes); apply any root transform to them separately. `cam_anterior_hilum` (v7) reference view only, not a step camera (it aims the step 2–5 port views).
- `rib_R5` + `rib_R6` are two halves of anatomical rib 5 (CONTEXT §7.2) — mesh names are not anatomical labels.
- Asset defects found here are logged in `docs/ASSET_ISSUES.md`.
