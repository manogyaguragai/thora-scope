## Notes

- Use node names (not mesh names) everywhere; see mismatch table.
- Morph target order differs between meshes (e.g. `tree_*` are alphabetical): always resolve by name via `morphTargetDictionary`, never by index.
- Bounding boxes/centroids are the unmorphed base pose (right lobes in their rest/inflated shape).
- Geometry dominates file size: textures are only 1.55 MiB of 18.67 MiB; morph targets multiply vertex data.
- Cameras and ports are scene roots, not children of `thorax_root` (see Nodes); apply any root transform to them separately.
- `rib_R5` + `rib_R6` are two halves of anatomical rib 5 (CONTEXT §7.2) — mesh names are not anatomical labels.
- Asset defects found here are logged in `docs/ASSET_ISSUES.md`.
